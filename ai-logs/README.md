# ai-logs

Records of the AI conversations used to build this project. Tokens and other private data have been removed.

| File | What it covers |
|---|---|
| [claude-code/session-summary.md](claude-code/session-summary.md) | Step-by-step summary of the Claude Code session: prompts, what the AI produced, what was checked or corrected |
| [claude-code/decisions.md](claude-code/decisions.md) | The approaches the AI proposed for each decision, and which one was chosen and why |

Tool: Claude Code (CLI), one long session in the terminal.
